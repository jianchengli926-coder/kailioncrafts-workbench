## 一、项目概述

### 1.1 项目定位
KaiLionCrafts 外贸获客 AI 工作台是阳江市锴利国际贸易有限公司（创始人：利建成 / Leo Li）的 AI 驱动型外贸获客工具，核心目标是：

```
Search → Visit → Trust → Inquiry → Sample → Quote → Order
```

### 1.2 技术栈
- **前端**：单文件 `index.html`（原生 JavaScript，无框架，内联 CSS/JS）
- **后端**：`server.js`（Node.js，Express 风格原生 HTTP）
- **知识库索引**：`kb_indexer.py`（Python，生成 kb_index.json / kb_manifest.json / kb_tree.json）
- **数据持久化**：localStorage（前端）+ JSON 文件（后端）
- **AI 模型**：GLM（在线，优先）→ Ollama（本地，兜底），Tavily（搜索，已禁用）
- **部署**：本地 launchd 服务 `com.kailioncrafts.prospect`，端口 8080

### 5.3 Policy 规则（必须严格遵守）
| 场景 | purpose | provider | 允许sensitivity |

- templateEligible=true 只能作为结构参考，不得作为事实
- pending/deprecated/conflictReview 不得作为确定事实
- 非法 purpose/provider 返回 HTTP 400，不自动降级
- 99 目录仅 local 可见，LAN/public 同步从 tree/status/search 排除

## 六、模块 C 深度分析系统说明

### 6.1 完整调用链
```
startCompanyDeepAnalysis(index)
  → POST /api/company/fetch（安全抓取：首页/About/Contact/Products/Wholesale）
  → extractCompanyInfo()（确定性提取：公司名/国家/电话/邮箱/产品/信号）
  → 构建evidence（每条结论有sourceUrl/confidence/extractionMethod）
  → 保存deepAnalysis（localStorage持久化）

runCompanyAIAnalysis(index)
  → 确认（已分析/已人工修改时提示）
  → retrieveKnowledgeForCompanyAnalysis(info, 'online_safe')
     → GET /api/kb/context（purpose=internal_ai&provider=online_glm，仅public）
  → 保护knowledgeFit人工修正（manuallyEdited时保留buyerFit/competitionRisk）
  → 构建AI Prompt：
     【公司基本信息】+【确定性提取】+【抓取页面】
     + buildKbContextForCompanyAnalysis(kf)（External Evidence与KB Context分离）
  → callAI(messages, { context: 'externalCompanyResearch', providerPolicy: 'online_safe' })
     → sanitizeFactsForAI(messages, 'externalCompanyResearch')（保留第三方事实，过滤KaiLion内部敏感数据）
     → GLM优先 → Ollama兜底
  → 解析JSON → 更新deepAnalysis
  → calculateDeepAnalysisScore(da)（深度评分）
  → calculateKnowledgeFit(da, kf)（买家/品牌/渠道/竞争风险）
  → 保存 → 渲染模态框
```

## 八、安全与事实约束

### 8.1 sanitizeFactsForAI 三种模式
| 模式 | context值 | 行为 |
|------|-----------|------|
| 第三方公司研究 | `externalCompanyResearch` | 保留有URL证据的第三方公司事实，仅过滤KaiLionCrafts内部敏感数据（成本价/底价/利润率/供应商结算价/内部价→`[内部数据已过滤]`） |
| 内部总结 | `generalInternal` | 基本不过滤 |
| 对外内容（默认） | `kaiLionOutbound` | 严格过滤FACT_SANITIZE_RULES中的未确认事实（自有工厂→strategic manufacturing partners，未确认MOQ/交期/产能→待确认，客户案例→待确认，免费样品→待确认，成本优势→可进一步评估，出口全球→可协助沟通出口需求） |

### 8.2 不得编造的内容（绝对禁止）
- 采购量、营业额、员工人数、决策人身份
- 是否一定愿意更换供应商、是否一定接受OEM
- Amazon销量、订单金额、采购预算
- SKU数量、MOQ、交期、成本优势、出口国家数量
- 工厂数量、产能、质保年限、美国仓库存或时效
- 免费样品、客户案例、销售额、利润率
- 合作工厂认证不得写成公司自有认证

### 8.3 静态文件安全
- kb_config.json / kb_index.json / kb_manifest.json / kb_tree.json / access_config.json / search_config.json → 静态访问全部 403
- /api/proxy/ → 403
- safeKbPath 路径穿越防护
- 原始 Markdown 不通过静态文件服务暴露
