# 锴利自研AI工具库

> KaiLionCrafts自主研发的产品图片处理与AI生图工具集，共7个工具

## 工具分类

### 🏷️ 产品命名
- **SKU命名工具** - 超级图片命名工具v4，产品库命名、自定义生成、批量重命名

### 🖼️ 图片处理
- **产品线稿工具** - 批量智能线稿转化，支持标注和高清导出
- **全品类视觉矫正** - 4K独立站主图矩阵系统，统一朝向和画质
- **白平衡校正工具** - 专业白平衡与调色工作站，批量处理
- **选片与RAW格式对齐系统** - JPG选片后自动对齐RAW原片

### 💡 AI生图
- **刀剪产品提示词** - 刀剪外贸独立站AI生图Prompt场景知识库
- **场景图反推** - 智能场景反推与双手解剖修复引擎

## 新员工使用指南

1. 在工作台左侧菜单点击「🛠️ 锴利自研AI工具库」
2. 选择需要的工具分类
3. 点击工具卡片进入对应工作台
4. 展开顶部「使用说明」查看操作步骤
5. 在嵌入的HTML工具中直接操作

## 添加新工具

后续开发新的HTML工具后：
1. 将HTML文件放到 `assets/tools/` 目录
2. 在 `assets/tools/tools_config.json` 中添加工具配置
3. 重启工作台即可显示

## 技术说明

- 所有工具为纯前端HTML，无需后端服务
- 在工作台中通过iframe嵌入运行
- 数据处理在浏览器本地完成，不上传服务器
- 支持批量处理，提高工作效率
