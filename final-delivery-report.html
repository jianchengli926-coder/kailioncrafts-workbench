故障转移规则

✅ 触发故障转移：
  • HTTP 408 / 429 / 500 / 502 / 503 / 504
  • 网络错误、连接失败、请求超时
  • 模型不存在或服务不可用
  • 单次请求超30秒 / 连续两次超15秒
❌ 不触发故障转移：
  • HTTP 401 / 403（API Key错误）
  • 参数错误、用户输入为空
  • 内容审核拒绝
  • 工具调用参数错误
⚠️ FLUX 状态：Ollama 0.35.0 不支持图像生成模型，FLUX.2 Klein 4B（5.7GB）虽已安装但标记为 runtime_unsupported，图像生成仅依赖 CogView 云端。不会伪造本地生图成功。
