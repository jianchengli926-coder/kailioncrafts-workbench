## 一、项目概述

这是一个**纯前端单文件应用**—— 没有后端、没有构建步骤、没有 npm 依赖。打开 HTML 即用，全部逻辑在 JS 里可直接阅读修改。

### 核心定位

为 KaiLionCrafts 外贸业务提供**产品目录的可视化编辑、报价管理、PDF/Excel 导出**一体化工作台。支持 8 个产品册子（4 品类 × 公开版 / 报价版），内置 333 张产品原图，数据采用 AES-256-GCM 加密保护报价信息。

### 关键指标



| 指标     | 数值                                     |
| ------ | -------------------------------------- |
| 总代码量   | 约 7,210 行                              |
| 核心业务逻辑 | `_editor_app.js` 5,415 行 / 296 KB      |
| 产品册子   | 8 本（4 品类 × 公开 / 报价）                    |
| 产品原图   | 333 张                                  |
| 缩略图    | 329 张                                  |
| 数据加密   | AES-256-GCM + PBKDF2-SHA256 (150000 次) |
| 访问密码   | 6 位数字（线上环境）                            |
| 总大小    | 约 39 MB                                |

### 2.2 技术栈



* **纯原生 JavaScript**（ES5 兼容写法，无框架、无构建）

* **HTML5 + CSS3**（CSS 变量、Grid、Flexbox、@media print）

* **WebCrypto API**（AES-256-GCM 解密、PBKDF2 密钥派生）

* **IndexedDB**（用户新上传图片的原始 Blob 存储，零压缩）

* **localStorage / sessionStorage**（编辑快照、门禁状态）

* **浏览器打印 API**（PDF 导出走原生打印，图片用原始字节）

### 3.3 算价引擎（核心业务逻辑）

基于全库 246 个 SKU 实测统计的折扣规则：



```
FOB 单价（基础价）
  ├─ 500–999 件阶梯价 = FOB × 0.94（让 6%）
  └─ 1,000+ 件阶梯价  = FOB × 0.88（让 12%）
```

**HTS 编码自动匹配**（美国海关编码，按品类 + 段码规则）：



| 品类      | 段码      | HTS Code   | 说明      |
| ------- | ------- | ---------- | ------- |
| SET（套刀） | SS / 任意 | 8211.10.00 | 套刀套装    |
| SC（剪刀）  | 任意      | 8213.00.00 | 剪刀      |
| OD（户外刀） | 任意      | 8211.92.00 | 户外刀     |
| KN（厨刀）  | 任意      | 8211.92.00 | 厨刀      |
| KA（配件）  | CB（砧板）  | 4419.19.00 | 木制品     |
| KA（配件）  | BBQ/TG  | 8215.20.00 | 烧烤 / 餐具 |
| KA（配件）  | 其他      | 8215.99.00 | 其余配件    |

> 所有自动计算均可手动覆盖，带锁标指示（🔒自动 / 🔓可手改 / ✎手动）。

### 3.5 安全机制（v3 真加密）

#### 门禁系统



* **仅线上 http/https 触发**：本地 file:// 双击直接跳过（利的要求：本地不要密码、部署后的链接要密码）

* **首帧即门禁**：脚本放在 `<head>` 里，加 `.kc-locked` 类，避免先渲染编辑器再盖住的闪烁

* **6 位数字密码输入框**：支持自动跳格、退格回跳、粘贴、方向键导航

#### 密码验证原理（关键！）



```
密码不写在任何前端文件里！
  │
  ▼
输入密码 → PBKDF2-SHA256(150000次迭代) → AES-256-GCM 密钥
  │
  ▼
用密钥解密 data/kc-1bc995ca.json
  ├─ 解得开 = 密码正确 → 进入编辑器
  └─ 解不开 = 密码错误 → 抖动动画 + 清空重输
```

> 即使有人把前端 JS 改成无条件放行，没有真密码依旧解不开数据、白屏。密码 = 
>
> **441723**

#### 加密参数



| 参数       | 值                 |
| -------- | ----------------- |
| 密钥派生     | PBKDF2-SHA256     |
| 迭代次数     | 150,000           |
| Salt     | 16 字节（随机，存在密文文件里） |
| 加密算法     | AES-256-GCM       |
| IV       | 12 字节（随机）         |
| Auth Tag | 16 字节（拼在密文尾部）     |

#### 数据文件名随机化



* 密文文件：`data/kc-1bc995ca.json`（`1bc995ca` 是随机 token）

* token 硬编码在 `_editor_app.js` 第 358 行：`var DATA_TOKEN = '1bc995ca';`

* 改文件名必须同步改这一行

### 3.6 PDF 导出（零压缩铁律）

**核心原则：图片永远走原始 Blob 字节，不经过 canvas 重编码。**



```
导出流程：
  1. 构建 #paper 容器（A4 210×297mm，3列×3行/页）
  2. 每页 9 张产品卡片（图片 + 名称 + SKU + 规格）
  3. 图片用原始文件字节（img/ 目录的原图，不重压缩）
  4. 调用 window.print() → 另存为 PDF
  5. @media print 隐藏全部 UI，只留 #paper
```

**踩坑记录（红线）：**



* ❌ 不要在 canvas 里重编码图片 → 两道重编码会让整页发灰、照片变糊

* ❌ 不要删 `@media print { html,body{height:auto;overflow:visible} }` → 会多出一张全空白首页

* ✅ 分页是「均分」不是「每页 9 张」，改分页要同步改 `pageOfIndex()`

### 3.7 Excel 导出



* 先弹预览窗口确认数据（HTML 表格渲染，与下载所见一致）

* 支持多 Sheet（按册子分）

* 包含：图片占位、SKU、产品名、规格、FOB 价、阶梯价、HTS 编码、交期

* 导出库 `_xlsx.js`（469 行，自研轻量实现）

### 3.8 撤销 / 重做系统



* **撤销栈粒度** = 一次「聚焦→编辑→失焦」= 1 步

* ⚠️ 不能在 `input` 事件里 pushUndo → 每敲一个字符压一条，撤销栈会爆

* 支持 Ctrl+Z / Ctrl+Y 快捷键

* 每本册子独立快照，存 localStorage

### 3.9 拖拽排序



* 左栏名片列表支持拖拽排序（⠿ 手柄）

* 拖动时有插入位置指示（上方 / 下方金色横线）

* 排序后可一键「恢复默认顺序」

* 排序结果存 localStorage，按数据指纹校验有效性

### 3.10 云同步（\_cloud.js，可选）



* **仅在 https 下激活**：`location.protocol === 'https:'`

* 多台电脑共享同一份数据（轮询 watch）

* 本源码包**没有配套云服务**，所以在你的环境里会：


  * 尝试连接 → Origin 不匹配 → 失败 → 静默回退读静态数据

  * 不会报错、不会卡住、不影响任何功能，等于自动停用

* 想彻底移除：删 `_cloud.js` + HTML 里对应 `<script>` 行

## 五、使用方法

在工作台目录下启动任意静态服务器：




1. **密码不落前端**：用 AES 解密成功与否验证密码，改前端代码没用
