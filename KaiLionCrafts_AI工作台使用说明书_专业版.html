①开始使用

5 分钟上手，先跑通「启动 → 登录 → 仪表盘 → 试一个AI功能」这条最短路径。

1. 启动工作台

双击桌面上的 AI工作台（workbench.kailioncrafts.com）.command 文件，系统会自动启动服务并打开浏览器。

访问方式地址说明
本地访问http://localhost:8501启动后自动打开
公网访问https://workbench.kailioncrafts.com需输入访问密码
局域网访问http://你的IP:8501同局域网其他设备可访问

2. 登录

打开工作台后，首先看到登录页面，输入访问密码 441723，点击「进 入」按钮即可。

首次登录后建议先做三件事
  • 查看「仪表盘」的 AI 引擎状态，确认模型连接正常。
  • 进「模型管理」点击「一键检测所有模型」，确认8个模型都能正常调用。
  • 在侧边栏「AI快速问答」随便问一个问题，验证AI功能正常。

3. 界面通用约定

  • 左侧导航：8 个分组（入门与总览 / 客户开发中心 / 锴利自研AI工具库 / 独立站SEO中心 / 销售与客户管理 / 知识与协作 / 订单与经营 / 系统与模型）。
  • 侧边栏顶部：当前AI模型选择器，可手动切换8个模型。
  • 侧边栏AI快速问答：折叠面板，任何页面都能快速提问AI。
  • AI按钮：每个功能页面都有AI按钮，点击后等待3-15秒生成结果。
  • 数据存储：所有数据本地JSON存储，不上传第三方服务器。

4. 这份说明书的符号

开箱即用 不需要任何外部配置，登录就能用。   可选增强 不配也能用，配了效果更好。   需先配置 不配置则功能无法完整工作。   AI增强 该功能已接入AI模型，可智能生成内容。

故障转移工作原理（重要）
  • 自动转移：调用AI时按优先级1→8逐个尝试，一个失败自动切下一个，用户无感知。

  • 手动切换：侧边栏顶部可手动指定使用某个模型，适合特定场景。
  • Trace记录：每次调用（含故障转移）都记录在AI调用Trace页面，可追溯。

⑤常见问题FAQ

使用过程中遇到问题，先在这里查找答案。

Q1: AI调用失败怎么办？

A: 工作台有8节点故障转移机制，一个模型失败会自动切换到下一个。如果所有在线模型都失败，会切换到本地Ollama模型。如果仍然失败，请检查网络连接。

Q2: AI生成速度慢怎么办？

A: 可以在侧边栏手动切换到轻量模型（Qwen2.5-7B），响应速度更快。或者在调用时使用 use_lite=True 参数。

Q3: 图像生成失败怎么办？

A: 图像生成使用智谱CogView-3-Flash模型，如果失败请检查：1）网络连接；2）API密钥是否有效；3）提示词是否包含违规内容。

Q4: 视觉分析（图片理解）失败怎么办？

A: 视觉分析使用智谱glm-4.6v-flash模型，请确保图片格式为jpg/png/webp，大小不超过10MB。

Q5: 如何添加新的AI模型？

A: 进入「设置中心」→「添加新API中转站」，填写供应商名称、API Base URL、API Key、模型名称等信息即可。

Q6: 数据存储在哪里？安全吗？

A: 所有数据（客户、订单、知识库、Trace）都存储在本地JSON文件中，位于工作台的 data/ 目录下。数据不上传到任何第三方服务器，完全本地存储。

Q7: 如何备份工作台数据？

A: 直接复制整个工作台文件夹即可完成备份。建议定期备份到外部硬盘或云存储。

Q8: 工作台支持多用户同时使用吗？

A: 支持。工作台运行在本地服务器上，同一局域网内的多台设备可以通过 http://你的IP:8501 同时访问。每个用户有独立的浏览器会话。

Q9: 忘记密码怎么办？

A: 访问密码是 441723。如果需要修改，编辑 app.py 第151行的密码判断，然后重启工作台。

Q10: 如何重启工作台？

A: 关闭终端窗口或按 Ctrl+C 停止服务，然后重新双击桌面的启动脚本。

Q11: AI生成的内容可以保存吗？

A: 大部分AI功能都有「保存到知识库」按钮，点击后内容会保存到公司知识库对应分类。部分功能（如开发信）会自动保存到个人工作空间。

Q12: 本地Ollama模型如何安装？

A: 1）从 https://ollama.com 下载安装Ollama；2）执行 ollama pull qwen2.5:7b 下载模型；3）启动工作台后会自动检测本地模型。

Q13: 故障转移是怎么工作的？

A: 调用AI时，系统按优先级1→8逐个尝试模型。如果第一个返回错误或超时，自动切换到第二个，以此类推。只有前7个在线模型全部失败时，才切换到第8个本地Ollama模型。整个过程用户无感知。

Q14: 如何查看AI调用记录？

A: 进入「AI调用Trace」页面，可以查看所有AI调用的详细日志，包括使用的模型、耗时、输入输出字符数、故障转移日志等。
