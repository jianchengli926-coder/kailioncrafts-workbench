故障转移规则

触发条件是否转移说明
HTTP 429 限流✅ 转移当前供应商配额耗尽，切下一个节点
连接超时✅ 转移网络或服务不可达
HTTP 5xx 服务器错误✅ 转移服务端临时故障
HTTP 401 未授权❌ 不转移API Key 配置错误，需人工修复
HTTP 403 禁止❌ 不转移权限或配额问题，需人工修复
参数错误 / Prompt 错误❌ 不转移请求本身有问题，切节点也会失败
在线节点全部失败✅ 切本地Ollama 本地模型兜底

10密码保护测试结果

安全机制

  • 密码来源：环境变量 WORKBENCH_ACCESS_PASSWORD，未硬编码到代码中
  • 比较方式：hmac.compare_digest 常量时间比较，防时序攻击
  • 失败锁定：连续 5 次失败后锁定 60 秒
  • 锁定期间：正确密码也被拒绝（FE-005 验证通过）
  • 锁定恢复：60 秒后自动恢复（FE-006 验证通过）

14模型使用逻辑说明

默认自动路由模式

  • 在线优先：文本请求先打 glm-4.7-flash，失败后逐级降级。
  • 逐级故障转移：429 / 超时 / 5xx 自动切下一个节点。
  • 全部在线失败后切本地：Ollama 本地模型兜底，保证离线可用。

手动模式

  • 用户在"模型管理"页手动选择某供应商 / 模型后，该类型请求固定使用所选模型。
  • 手动模式下不自动切换，避免演示时模型跳变。

本地模型互斥锁

  • 同一时间只加载一个本地大模型（GPU 显存限制）。
  • 切换前释放旧模型，请求结束后卸载。
  • 仪表盘显示"Ollama 服务运行中，检测到 N 个本地模型"。

故障转移触发条件

触发不触发
  • 429 限流
  • 连接超时
  • 5xx 服务器错误
  • 401 未授权（API Key 错误）
  • 403 禁止（权限问题）
  • 参数错误 / Prompt 错误
📌 图像生成：仅 cogview-3-flash（在线）。Ollama 不支持图像生成时，UI 诚实显示"暂不支持本地生图"，不假装可用。
