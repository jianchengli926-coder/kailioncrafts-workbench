# KaiLionCrafts AI客户开发工作台

> 基于阳江五金刀剪产业知识库的B2B外贸客户开发AI工作台

## 快速开始

### 1. 安装依赖
```bash
cd AI客户开发工作台
pip3 install -r requirements.txt
```

### 2. 配置API密钥
```bash
cp .env.example .env
# 编辑 .env，填入你的豆包API Key
# AI_PROVIDER=doubao
# DOUBAO_API_KEY=你的密钥
```

**豆包API Key获取方式**：
- 登录 [火山引擎方舟](https://console.volcengine.com/ark)
- 开通模型服务（doubao-pro-32k / doubao-lite-32k）
- 创建API Key

### 3. 启动工作台
```bash
# 方式一：用启动脚本
chmod +x run.sh
./run.sh

# 方式二：直接启动
python3 -m streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`

## 部署方式

### 工作台是什么形式？
本工作台是一个 **Streamlit Web 应用**，本质是一个网页。启动后在浏览器中打开使用，不需要安装客户端。

### 三种使用方式

| 方式 | 适用场景 | 访问地址 |
|------|----------|----------|
| **本地单人使用** | 自己一个人用 | `http://localhost:8501` |
| **局域网多人使用** | 办公室同事一起用 | `http://你的电脑IP:8501` |
| **服务器部署** | 随时随地访问，外网可用 | 你的域名或服务器IP |

### 1. 局域网多人访问（推荐办公室使用）
启动脚本已默认配置 `--server.address=0.0.0.0`，同事在同一WiFi/网络下可通过你的IP访问：

```bash
./run.sh
# 启动后会显示局域网地址，例如：
# 🌐 局域网访问: http://192.168.1.22:8501
```

把这个地址发给同事，他们在浏览器打开即可使用。

**注意**：你的电脑需要保持开机和运行工作台，同事才能访问。

### 2. 本地大模型接入
工作台支持通过 **Ollama** 接入本地大模型，完全离线、免费、不消耗API额度：

1. 安装 [Ollama](https://ollama.com/)
2. 下载模型：`ollama pull qwen2.5:7b`（千问2.5）或 `ollama pull llama3.1`
3. 在工作台「设置」中选择 `Ollama（本地模型）`
4. Base URL 填 `http://localhost:11434/v1`
5. 模型名填 `qwen2.5:7b`（或你下载的模型名）
6. API Key 随便填（如 `ollama`）

支持的本地模型：千问2.5、Llama 3.1、DeepSeek、Mistral、Phi 3等所有Ollama支持的模型。

### 3. 部署到服务器（可选）
如果需要外网随时访问，可以部署到你的 Hostinger 服务器：
- 需要支持Python的主机（Hostinger VPS或云主机）
- 用 Nginx 反向代理到 Streamlit
- 配置域名和HTTPS
- 具体部署可以后续协助配置

## 客户开发工作流

```
1. 找到潜在客户（Google/LinkedIn/展会/海关数据）
   ↓
2. 🎯 客户分析：输入客户信息 → AI打分分级
   ↓
3. 💾 保存到客户管理（A级优先跟进）
   ↓
4. ✉️ 生成开发信：AI个性化撰写 → 人工审核 → 发送
   ↓
5. 🔄 跟进序列：第3/7/14/21天自动生成跟进邮件
   ↓
6. 💬 客户问答：客户回复后，AI生成专业回复
   ↓
7. 📦 产品推荐：根据需求推荐具体SKU
   ↓
8. 👥 更新客户状态：跟进中→已报价→已成交
```

## 注意事项

1. **AI生成内容必须人工审核**后再发送，特别是发给重要客户
2. **不要让AI编造产品参数**，所有规格以SKU数据和产品规格库为准
3. **客户数据存在本地** `data/customers.json`，建议定期备份
4. **演示模式**：不配置API Key也能打开界面，但AI回复为模拟内容
5. **术语一致性**：工作台已内置KaiLion标准术语库，英文翻译会遵循标准译法

## 常见问题

**Q: 没有豆包API Key能用吗？**
A: 可以打开界面使用客户管理和知识库浏览功能，但AI生成功能为演示模式。

**Q: 可以用OpenAI/Codex吗？**
A: 可以，在.env中设置 `AI_PROVIDER=openai` 并填入OpenAI API Key。

**Q: 客户数据存在哪里？**
A: 存在本地 `data/customers.json`，不会上传到任何服务器。

**Q: 怎么备份客户数据？**
A: 直接复制 `data/customers.json` 文件即可，或在客户管理页面导出CSV。
