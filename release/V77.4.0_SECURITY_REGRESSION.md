## 九、已知安全边界（非缺陷，设计如此）

1. **MX查询仅做DNS级验证**: 不验证邮箱真实存在性（避免调用付费API），仅验证域名MX记录存在
2. **开发信质检为纯规则**: 不调用AI做语义分析，避免误判和额外成本
3. **本地存储为主**: 客户数据存储在localStorage和本地JSON，不涉及云端同步
4. **单人使用设计**: 无多用户权限系统（Leo明确排除），访问控制为单密码门控
5. **测试密码临时机制**: UAT测试时临时设置明文密码，测试后立即恢复hash配置
