# 广交会客户档案与开发信生成规范

> 所有Subagent必须严格遵循此规范，确保输出格式一致、可直接整合到工作台。

## 一、输出文件

每个Subagent处理完本组客户后，必须生成一个JSON文件：
- 路径：`广交会分析_分组数据/results_batch{N}_group{M}.json`
- 格式：`{"customers": [...], "drafts": [...]}`

## 四、开发信写作规范

### 英文发送版要求
- **150词以内**，三短段结构
- 第一段：个性化开场（提及客户具体产品/业务，证明做过功课）
- 第二段：我是谁+核心卖点（2-3个最相关的卖点）
- 第三段：行动号召（WhatsApp call / 索取catalog / 样品）
- 语气：Professional, Clear, B2B, Trustworthy
- 禁止：过度推销、关键词堆砌、不自然表达

### 签名固定格式
```
Best,
Leo Li
KaiLionCrafts | WhatsApp: +86 131-3800-6564
kailioncrafts.com/{对应品类页面}
```

## 五、背调8维度说明

1. **公司概况**：通过网站了解主营产品、成立时间、规模、市场定位
2. **决策人信息**：联系人已有（Excel），补充职位；通过网站About/Team页面查找
3. **联系方式**：邮箱、电话、网站已有；确认是否有效
4. **痛点分析**：基于网站内容分析（如产品种类少、价格高、需要新品等）
5. **采购意向**：判断是否采购刀剪/厨房用品（高/中/低 + 理由）
6. **竞品分析**：网站上销售的竞品品牌（如有）
7. **供应链分析**：现有供应商国家（从产品描述/Made in推断）
8. **切入点建议**：用什么卖点接触该客户最有效

## 六、评分标准

### scores.total（综合评分1-100）
- industry（行业匹配度）：客户是否在五金/刀剪/厨房行业
- product（产品匹配度）：客户是否采购我们的产品品类
- companyType（客户类型价值）：品牌商/进口商 > 分销商 > 零售商
- purchaseSignal（采购信号）：是否有明确采购需求迹象
- contactQuality（联系方式质量）：有具体联系人+邮箱 > 通用邮箱

### grade
- A：≥80分（高优先级）
- B：60-79分（中优先级）
- C：<60分（低优先级）

### portrait.priorityScore
与scores.total一致或微调（考虑国家等级、品类匹配等）

## 七、国家等级映射
- S级：美国、德国、英国、日本、澳大利亚、加拿大
- A级：法国、意大利、西班牙、荷兰、瑞士、瑞典、挪威、丹麦、芬兰、爱尔兰、奥地利、新西兰、比利时、葡萄牙、以色列、韩国、新加坡
- B级：中东、东南亚、拉美、东欧
- C级：印度、巴基斯坦、孟加拉、非洲等

## 八、注意事项

1. **客户信息必须来自Excel**，不编造邮箱、电话、地址
2. **背调信息基于网站内容**，不确定的标注"待确认"
3. **绝对不能自动发送邮件** — 只生成内容
4. **对于不匹配的客户**（如纯 Marine Hardware、家具公司等），productCategory填"不匹配"，意向等级填"低"，开发信用更通用的五金采购角度
5. **有网站的客户必须访问网站**进行背调；无网站的客户基于公司名+国家做推断
6. **去重**：同一公司只生成一个档案
7. **代码/文件用English注释**，客户内容用英文，内部分析可用中文
