📚 一、修复：企业知识库文档列表加载问题

问题现象：企业知识库页面显示"加载分类树..."，文档列表为空（"暂无文档"），但顶部统计数据（588文档/9156切片）正常显示。

1.1 根因定位

后端 API 正常
/api/kb/tree 返回 16 个分类、588 篇文档，数据完整
前端数据已加载
kbBrowserState.tree 包含 16 个分类，treeLoading=false
根因：缺少 renderView()
kbLoadTree() 异步加载完成后，只设置了 kbBrowserState.tree，但没有调用 renderView() 触发页面重新渲染。页面停留在加载前的"加载分类树..."状态。

1.2 修复内容

// app.js - kbLoadTree() 函数末尾添加 kbBrowserState.treeLoading = false; // 修复：数据加载完成后触发重新渲染 if (typeof renderView === 'function') renderView();

🤖 二、实现：后端真实云端模型调用

问题：model-router.js 的 callCloudModel() 是 mock 实现，直接返回 not_configured 错误，没有真实调用智谱 GLM API。后端路由模式（useServerRouter）下在线模型完全不可用。

2.1 实现内容

  • 真实 API 调用：使用 Node.js https 模块发送 POST 请求到智谱 GLM API（OpenAI 兼容格式 /chat/completions）
  • 配置读取：从 api_config.json 读取 endpoint、apiKey、timeout 配置
  • 请求格式：支持 string / array / object 三种 prompt 格式，统一转换为 messages 数组
  • 响应解析：解析 OpenAI 兼容格式（choices[0].message.content），处理 error、empty_response、parse_error
  • 错误处理：网络错误（ECONNREFUSED）、超时、HTTP 错误码、API 错误响应
  • 未配置处理：apiKey 为空时返回明确的 not_configured 错误（recoverable: true），触发故障转移到本地模型
  • Mock 兼容：保留 mockProvider 参数，测试时可注入 mock

2.2 故障转移类型扩展

原 FAILOVER_ALLOWED_TYPES 不包含 not_configured，导致云端未配置时不触发故障转移。已扩展：

// 修复前 const FAILOVER_ALLOWED_TYPES = new Set([ 'timeout', 'abort', 'connection_refused', 'econnrefused', 'network_error', 'ollama_unavailable', 'slow_response', 'rate_limited', 'service_unavailable' ]); // 修复后（新增4种可转移错误） const FAILOVER_ALLOWED_TYPES = new Set([ 'timeout', 'abort', 'connection_refused', 'econnrefused', 'network_error', 'ollama_unavailable', 'slow_response', 'rate_limited', 'service_unavailable', 'not_configured', 'config_error', 'empty_response', 'parse_error' ]);
