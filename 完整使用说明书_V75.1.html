一、工作台介绍

锴利外贸获客工作台是一款专为外贸企业打造的全流程获客管理系统，集成了客户管理、开发信撰写、AI智能获客、销售漏斗、社媒监控等24个功能模块。

核心特点

🔒 本地私有化部署数据全部存在本地浏览器，不上传云端，安全可控
🤖 AI智能驱动支持在线免费模型+本地Ollama模型，AI写开发信、客户画像、SEO内容
📊 全流程管理从获客→开发信→跟进→询盘→报价→订单→售后，全流程覆盖
🌐 三种访问方式本地访问、局域网访问、公网访问（Cloudflare Tunnel）
⚡ 开机自启动launchd守护进程，Mac开机自动运行，无需手动启动
💾 数据自动保存所有操作自动保存到localStorage，支持CSV导入导出

技术规格

项目规格
前端单文件HTML应用（index.html，约14000行，468个函数）
后端Node.js本地服务器（server.js，341行，端口8080）
数据存储浏览器localStorage（前缀 kailion_ark_）
AI模型15个模型（智谱5个+硅基流动4个+Gemini 3个+本地Ollama 3个）
功能页面24个

八、常见问题 FAQ

Q1：工作台打不开怎么办？

A：按以下步骤排查：

  1. 确认电脑已开机，服务器已自动启动
  2. 在浏览器输入 http://localhost:8080
  3. 如果打不开，在终端运行 lsof -i :8080 查看服务器是否运行
  4. 如果服务器没运行，运行 launchctl kickstart -k gui/$(id -u)/com.kailioncrafts.prospect 重启
  5. 如果还是不行，检查项目文件夹是否存在（外置硬盘是否连接）

Q2：数据会丢失吗？

A：数据存储在浏览器localStorage中，正常使用不会丢失。但以下情况会导致数据丢失：

  • 清除浏览器数据/缓存
  • 更换浏览器（Chrome的数据在Safari中看不到）
  • 更换电脑
  • 浏览器用户配置文件损坏
💡 建议：每周备份一次数据（设置页面→导出全部数据），备份文件保存到网盘或移动硬盘。

Q3：AI功能用不了怎么办？

A：按以下步骤排查：

  1. 检查网络连接是否正常
  2. 进入"设置"页面，检查API Key是否正确配置
  3. 点击"模型测速"，查看哪些模型可用
  4. 如果在线模型都不可用，确保本地Ollama已启动（运行 ollama serve）
  5. 工作台会自动故障转移到可用模型，无需手动切换

Q4：局域网同事无法访问怎么办？

A：按以下步骤排查：

  1. 确认你的电脑和同事的电脑在同一个WiFi/局域网下
  2. 查看你的电脑IP地址（系统设置→网络→IP地址）
  3. 同事浏览器输入 http://你的IP:8080
  4. 检查Mac防火墙是否阻止了8080端口（系统设置→网络→防火墙）
  5. 确认服务器绑定地址是0.0.0.0（允许局域网访问）

Q5：公网访问不了怎么办？

A：按以下步骤排查：

  1. 确认本地工作台能正常访问（localhost:8080）
  2. 确认Cloudflare Tunnel进程在运行
  3. 检查Cloudflare Tunnel配置是否正确
  4. 查看Cloudflare Tunnel日志排查错误

Q6：怎么修改访问密码？

A：进入"设置"页面，找到"安全设置"区域，输入旧密码和新密码，点击保存即可。

Q7：开发信怎么发送？

A：工作台只生成开发信草稿，发送需要你手动完成：

  1. 在开发信编辑器中点击"📋 复制"按钮
  2. 打开Gmail/Outlook/企业邮箱
  3. 粘贴开发信内容，填写收件人
  4. 点击发送
  5. 回到工作台，点击"✅ 标记已人工发送"记录状态
💡 提示：也可以配置SMTP服务器实现自动发送，但需要企业邮箱的SMTP授权码。

Q8：换电脑了数据怎么迁移？

A：按以下步骤迁移：

  1. 在旧电脑上：设置→导出全部数据，下载JSON文件
  2. 在新电脑上：安装工作台（复制项目文件夹）
  3. 在新电脑上：设置→导入数据，选择JSON文件
  4. 确认导入，数据迁移完成
