5 分钟上手，先跑通「登录 → 看板 → 加一个客户」这条最短路径。

首次登录后建议先做三件事
  • 进「设置 → 供应商管理」配置一个免费 AI 模型 API Key（推荐智谱 GLM，永久免费），这一步能解锁整套 AI 能力。
  • 进「设置」完善公司业务背景、个人背景、主推产品库，AI 写开发信时会自动引用。
  • 进「产品管理」添加您的产品信息，后续快速报价功能会用到。

3. 界面通用约定

  • 左侧导航：4 个分组（核心业务 / AI智能 / 营销推广 / 支撑工具），共 20 个页面。
  • 顶部状态栏：显示工作台名称、当前页面、通知提醒（待跟进客户数量）。
  • 主内容区：显示当前选中页面的详细内容，所有操作都在这里完成。
  • 弹窗操作：很多功能会弹出操作窗口，操作完成后点击「确定」或「保存」，或点击右上角「×」关闭。按 Esc 键也可以关闭弹窗。
  • 数据自动保存：工作台所有数据自动保存到本地（localStorage），无需手动保存。

4. 这份说明书的符号

③AI模型与外部依赖

这是整份说明书最重要的一张表。工作台本身开箱即用，但想让「AI获客」「AI背调」「AI写开发信」「AI回复建议」真正发挥作用，需要把 AI 模型配起来。所有在线模型均为免费，本地模型作为兜底。

类别对应的功能在哪里配置 重要度可选服务（全部免费）不配置会怎样
智谱 GLMAI解析、公司背调、AI画像、开发信生成、回复建议、沟通总结设置 → 供应商管理强烈建议4个免费模型：GLM-4.7 Flash（深度思考）、GLM-4.6V Flash（视觉理解）、GLM-4 Flash（文本生成）、CogView-3 Flash（图像生成）。一个 API Key 调用所有模型。AI 功能不可用，其余模块不受影响。
硅基流动开源大模型推理，速度快设置 → 供应商管理建议配置多个开源模型免费额度，注册即送 Tokens。少一个故障转移选项，不影响主功能。
Google GeminiGoogle 出品大模型，能力强设置 → 供应商管理建议配置11个免费模型，推荐 gemini-3.1-flash-lite（每天500次免费调用）。少一个故障转移选项，不影响主功能。
本地 Ollama本地运行模型，不需要联网，数据不出本机设置 → 本地模型兜底必备3个本地模型：千问2.5（文本）、DeepSeek（推理）、视觉模型（图像理解）。0成本，需安装 Ollama。在线模型全部失败时无兜底，AI 功能暂时不可用。
配置优先级建议（按这个顺序做，性价比最高）
  • 第 1 步：智谱 GLM（免费）—— 一个 Key 解锁 4 个免费模型，AI 解析、公司背调、开发信生成、回复建议全部可用。
  • 第 2 步：本地 Ollama（免费）—— 安装 Ollama 后下载千问2.5模型，作为在线模型的兜底，断网也能用 AI。
  • 第 3 步：Gemini / 硅基流动（免费）—— 增加更多故障转移选项，提高 AI 功能稳定性。
智能故障转移机制 工作台内置故障转移：默认模型 → 在线生成模型 → 在线推理模型 → 本地 Ollama 模型。当一个模型调用失败时自动切换到下一个，确保 AI 功能始终可用。您不需要手动干预，系统自动处理。

📊 数据看板

核心业务 · 首页 开箱即用

这一页是干什么的：工作台的首页，提供业务全局概览，让您一眼掌握所有重要信息。每天早上打开工作台先看这里，了解今日最重要的任务。

主要功能

  • 今日最重要的事：显示待发送开发信数量和高匹配客户数量，按优先级排序
  • 预警提醒：超时未跟进客户、待回复邮件、待处理询盘等预警信息
  • 客户质量分布：A/B/C 三级客户分布进度条，优质客户占比一目了然
  • 跟进状态统计：今日待跟进、跟进超时、已回复客户、沟通记录总数（4个彩色卡片）
  • 工作台使用统计：今日新增客户/开发信/跟进/沟通，本周/本月新增，客户回复率
  • 客户增长趋势图：最近 30 天客户新增趋势
  • 国家分布图：客户按国家分布统计
  • 来源分布图：客户按来源（AI搜索/海关数据等）分布
  • 今日待联系客户：按优先级排序的今日需跟进客户列表

操作步骤

1
点击左侧导航栏「📊 数据看板」，或按快捷键 g + d
2
浏览各项统计数据，了解业务整体状况
3
点击「今日待联系客户」中的客户，可直接进入客户详情页
4
点击统计卡片可跳转到对应功能页面（如点击「本月触达」跳转到触达中心）
使用建议 建议每天早上打开工作台先看数据看板，了解今日最重要的任务，然后按优先级处理。重点关注「超时未跟进」和「今日待跟进」客户，这些是最容易丢单的环节。

主要功能

操作步骤：添加新客户

✉️ 开发信

核心业务 · 获客关键 AI 功能

这一页是干什么的：帮助您高效撰写和管理外贸开发信，支持 AI 生成、12 个专业模板、草稿管理、分类筛选等功能。

主要功能

  • AI 生成开发信：输入客户信息和产品信息，AI 自动生成个性化开发信 AI 功能
  • 邮件模板库：12 个专业模板，6 大分类（初次开发/跟进邮件/报价跟进/样品跟进/关系维护/回复处理）
  • 草稿管理：保存和管理所有开发信草稿，支持编辑、删除、复制
  • 分类筛选：按模板分类快速筛选模板
  • 一键复制：复制开发信内容到剪贴板，直接粘贴到邮件客户端发送

操作步骤：使用模板写开发信

1
点击左侧导航栏「✉️ 开发信」，或按快捷键 g + e
2
在模板库中选择合适的分类（初次开发/跟进邮件等）
3
点击模板卡片查看完整内容
4
根据客户情况修改模板内容（公司名、产品名、联系方式等）
5
点击「📋 复制全文」按钮，复制到剪贴板
6
打开您的邮件客户端（Gmail/Outlook/企业邮箱等），粘贴内容并发送
开发信要点 标题吸引人、正文简短（不超过 100 词）、突出客户价值、明确行动号召、签名包含联系方式。个性化开发信回复率比群发高 3-5 倍。建议每封开发信都根据客户情况进行个性化修改，不要直接群发模板。
注意 工作台负责生成和管理开发信内容，发送需要使用您自己的邮件客户端。工作台不直接发送邮件，需要复制后粘贴到邮件客户端发送。

这一页是干什么的：管理所有客户跟进任务，确保不会遗漏任何重要跟进。支持桌面通知、超时提醒、SOP 流程引导。

1

局域网访问

同一 WiFi 下的同事可以通过您的电脑 IP 访问工作台。

1
确保服务器已启动（监听 0.0.0.0:8080，允许外部访问）
2

注意 如果同事无法访问，请检查您的 Mac 防火墙设置（系统设置 → 网络 → 防火墙），确保允许 node 接收连接。

⑦常见问题 FAQ

使用过程中遇到问题，先在这里查找答案。

Q1：工作台数据保存在哪里？会丢失吗？

A：工作台所有数据保存在您的浏览器本地（localStorage），不会上传到任何服务器。只要您不清除浏览器数据，数据就不会丢失。建议定期导出 JSON 备份文件，双重保险。

Q2：换电脑了，数据怎么迁移？

A：在旧电脑上导出全部数据（JSON 备份），然后在新电脑上打开工作台，进入设置页面的数据导入功能，导入之前导出的 JSON 文件即可。

Q3：AI 模型调用失败怎么办？

A：工作台内置故障转移机制，当一个模型失败时会自动切换到其他模型。如果所有在线模型都失败，会自动使用本地 Ollama 模型兜底。您也可以在设置页面检查模型配置，确保 API Key 正确且有额度。

Q4：局域网同事无法访问怎么办？

A：请检查以下几点：

  • 确保服务器已启动且监听 0.0.0.0:8080
  • 确保您和同事在同一个 WiFi 网络下
  • 检查您的 Mac 防火墙设置，允许 node 接收连接
  • 确认 IP 地址正确（在系统设置→网络中查看）

Q5：公网访问不了怎么办？

A：公网访问需要以下条件同时满足：

  • 您的 Mac 电脑保持开机
  • 工作台服务器运行（端口 8080）
  • cloudflared 服务运行
  • Cloudflare Tunnel 配置正确
如果以上都正常但仍无法访问，请检查 Cloudflare Tunnel 状态或联系管理员。

Q6：怎么修改访问密码？

A：访问密码在代码中设置，需要修改 index.html 文件中的密码验证逻辑。建议联系管理员修改，修改后需要重新提交备份。

Q7：开发信怎么发送？

A：工作台负责生成和管理开发信内容，发送需要使用您自己的邮件客户端（Gmail、Outlook、企业邮箱等）。生成开发信后点击「复制全文」，然后粘贴到邮件客户端发送即可。

Q8：可以同时多少人使用？

A：工作台是单文件 HTML 应用，理论上支持多人同时访问。通过局域网或公网访问同一个服务器实例，团队成员可以共享数据。

Q9：怎么更新工作台版本？

A：工作台代码托管在 GitHub 上，更新时拉取最新代码即可。更新前建议先导出数据备份，更新后数据不会丢失（数据保存在浏览器 localStorage 中，与代码分离）。

Q10：工作台支持手机访问吗？

A：支持。通过局域网（http://192.168.1.22:8080）或公网（https://prospect.kailioncrafts.com）可以在手机浏览器中访问。工作台做了响应式适配，手机上也能正常使用主要功能。
