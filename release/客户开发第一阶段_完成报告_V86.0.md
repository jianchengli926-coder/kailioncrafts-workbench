## 二、功能详细说明

### 功能1.1：全网搜客增强

**视图入口**：侧边栏「🔍 全网搜客」（key: `customerDevSearch`）

**核心能力**：

1. **多数据源整合**
   - AI搜索：调用 `POST /api/search` 联网搜索，再经 `callAI` 结构化提取公司信息
   - 独立站搜索：通过 query 包裹实现"独立站品牌/工厂"模式
   - 平台店铺搜索：阿里巴巴/亚马逊风格供应商搜索
   - 全部基于免费API，无付费服务

2. **四品类关键词矩阵**（内置，点击芯片一键填入）
   - 户外刀：outdoor knife manufacturer, hunting knife supplier, EDC knife wholesale, tactical knife factory, pocket knife OEM
   - 厨房刀：kitchen knife manufacturer, chef knife supplier, kitchenware wholesale, knife set factory, santoku knife OEM
   - 剪刀：scissors manufacturer, professional shears supplier, garden pruners wholesale, kitchen shears factory, tailor scissors OEM
   - 厨房用品：kitchen accessories manufacturer, cooking utensils supplier, BBQ tools wholesale, cutting board factory, peeler grater OEM

3. **批量搜客**
   - 支持一次输入多个关键词（换行分隔，最多8个）
   - 串行搜索 + 实时进度日志
   - 结果按网站域名合并去重，联系方式互补合并

4. **搜索结果卡片**
   - 展示字段：公司名称、网站链接、国家、客户类型、邮箱、电话、匹配品类、匹配度评分（0-100，颜色分级）
   - 三个操作按钮：
     - **查看详情**：模态框展示全字段
     - **导入台账**：写入 `S.customers`，去重校验（按网站域名/公司名），导入后变"已导入"态
     - **AI背调**：设置 `window._cdPendingIntel` 并跳转到背调页面，自动填入待背调客户

5. **搜索历史**
   - 持久化到 `S.cdSearchHistory`（关键词/品类/结果数/时间）
   - 可清空历史

6. **导入客户字段兼容**
   - id格式：`cust_<timestamp>_<random>`
   - 同时写入 `name` + `company` 双字段，兼容旧模块
   - 自动初始化 `cdProfile`（客户类型/意向等级）、`cdCompleteness`（完整度评分）、`leadScore`、`tags`
   - `source: 'cd_search'`，`status: '未开发'`

### 功能1.2：AI背调一页纸增强（8维度）

**视图入口**：侧边栏「📋 客户背调画像」→ 背调Tab（key: `customerDevIntel`）

**背调8维度**：

| 维度 | 包含字段 |
|---|---|
| ① 公司概况 | 公司名、成立时间、规模、地址、官网、业务范围 |
| ② 决策人信息 | 姓名、职位、邮箱、LinkedIn、采购决策权 |
| ③ 联系方式 | 邮箱、电话、WhatsApp、社媒账号 |
| ④ 痛点分析 | 当前供应商问题、成本压力、品质问题、交期问题、品类缺口 |
| ⑤ 采购意向 | 采购品类、采购量、采购周期、预算范围、决策流程 |
| ⑥ 竞品分析 | 当前供应商、竞品价格带、竞品优劣势、我们的差异化机会 |
| ⑦ 供应链现状 | 是否有中国供应商、采购地区、OEM/ODM经验 |
| ⑧ 切入点建议 | 最佳沟通角度、推荐卖点、推荐产品、首次沟通话术 |

**背调流程**（四步进度指示器）：
1. **抓取官网**：调用 `POST /api/fetch` 抓取客户官网内容
2. **联网搜索**：调用 `POST /api/search` 搜索公司公开信息
3. **AI分析**：调用 `callAI(gpt-5.6-terra)`，system prompt注入KaiLionCrafts公司卖点，生成8维度JSON
4. **完成**：结构化存储到 `customer.cdIntel`

**置信度标注**：
- 🟢 高（High）：官网 + 多来源验证
- 🟡 中（Medium）：单一来源
- 🔴 低（Low）：纯AI推理无来源

**其他特性**：
- 历史版本：每次重新生成前旧版存入 `S.cdIntelHistory`
- 待背调传入：从搜客模块跳转时自动读取 `window._cdPendingIntel` 填入表单
- 新客自动建档：背调后若客户不在台账，自动新建记录并回填邮箱/电话/WhatsApp/决策人
- 可重新生成（更新信息）

**公司卖点融入**（背调system prompt）：
阳江产业带（中国75%刀剪产自阳江）、4家合作工厂（家族股权模式）、创始人Leo直接对接、返乡创业青年+政府背书、阳江刀剪协会+大厂资源整合、免费营销素材套餐、工厂宣传片可打客户Logo、OEM/ODM代工、SGS LFGB + FDA认证、工厂直供价（低于贸易商20%）、出口130+国家

**视图入口**：「📋 客户背调画像」→ 画像Tab

**画像6维度**：

| 维度 | 说明 |
|---|---|
| 意向等级 | 高/中/低（基于背调采购意向、匹配度、活跃度） |
| 客户类型 | 品牌商(Brand)/进口商(Importer)/分销商(Distributor)/电商卖家(E-commerce)/零售商(Retailer) |

## 三、技术实现

### 架构模式
- **IIFE封装**：每个模块独立作用域，不污染全局
- **NAV.push注入**：通过现有导航系统注入3个新导航项
- **renderView拦截**：包装全局 `renderView`，当 `currentView` 匹配新视图key时渲染模块视图，否则链式调用原renderView
- **状态持久化**：所有新字段接入 `S` 对象，调用 `persist()` 保存到localStorage

### 新增状态字段
```javascript
S.cdSearchHistory = [];      // 搜索历史
S.cdSmartGroups = [];         // 智能客群
S.cdSearchResults = [];       // 搜索结果缓存
S.cdIntelHistory = [];        // 背调历史版本
customer.cdIntel = {};        // 背调结果（8维度+置信度+来源）
customer.cdProfile = {};      // 客户画像（6维度）
customer.cdCompleteness = {}; // 完整度评分（5维度+缺失项）
```

### CSS规范
- 所有新CSS类使用 `cd-` 前缀
- 通过创建 `<style>` 标签动态注入
- 包含 `@media (max-width:768px)` 响应式规则

### 复用现有能力
- `callAI(messages, opts)` — AI调用（gpt-5.6-terra）
- `POST /api/search` — 联网搜索
- `POST /api/fetch` — 网页抓取
- `S.customers` — 客户台账数据
- `persist()` — 状态持久化
- `NAV.push()` — 导航注入
- `go(view)` — 视图导航
- `toast()` / `esc()` / `uid()` / `addTimelineEvent()` — 通用工具函数

## 五、使用说明

### 1. 全网搜客
1. 点击侧边栏「🔍 全网搜客」
2. 选择品类（点击关键词芯片自动填入）或手动输入关键词
3. 选择搜索范围（全网/独立站/平台店铺）
4. 点击「开始搜索」（批量搜索时每行一个关键词）
5. 搜索结果以卡片形式展示，可：
   - 「查看详情」查看完整信息
   - 「导入台账」将客户加入客户管理
   - 「AI背调」跳转到背调页面自动填入

### 2. AI背调
1. 点击侧边栏「📋 客户背调画像」
2. 在「背调」Tab选择客户（或从搜客页面跳转自动填入）
3. 确认公司名、官网、国家后点击「开始背调」
4. 等待四步流程完成（抓取官网→联网搜索→AI分析→完成）
5. 查看8维度背调报告，可「重新生成」更新信息

### 3. 客户画像
1. 在「客户背调画像」页面切换到「画像」Tab
2. 选择客户，查看AI自动生成的画像（意向等级/客户类型/国家等级/品类匹配/优先级/推荐策略）
3. 可手动调整各维度，自动保存
4. 全部客户按优先级排序展示

### 4. 智能筛选
1. 点击侧边栏「🎯 智能筛选」
2. 组合选择6个筛选维度（品类/区域/客户类型/意向/状态/完整度）
3. 实时查看筛选结果和统计
4. 点击「保存为智能客群」可保存当前筛选条件
5. 已保存客群可一键应用或删除

### 5. 信息完整度
1. 在「客户背调画像」页面切换到「完整度」Tab
2. 查看所有客户的完整度评分（低分优先）
3. 点击客户查看缺失项明细（红色chip高亮）
4. 点击「AI补充信息」自动搜索并填充缺失字段（不覆盖已有数据）

## 六、注意事项

1. **AI调用依赖**：背调和搜客的AI提取依赖 `gpt-5.6-terra` 模型路由配置，若模型不可用会提示错误
2. **401错误**：页面加载时出现的2个401 Unauthorized是模型API认证相关，与新模块无关
3. **数据兼容**：导入客户时同时写入 `name` 和 `company` 双字段，确保新旧模块都能正确显示
4. **模块间通信**：搜客→背调通过 `window._cdPendingIntel` 全局变量传递待背调客户
5. **renderView拦截链**：search模块先包装renderView，intel模块后包装，形成正确的链式调用，不影响原有视图
6. **后续阶段**：第二阶段将基于本阶段的客户画像和背调结果，实现个性化开发信生成和跟进序列
