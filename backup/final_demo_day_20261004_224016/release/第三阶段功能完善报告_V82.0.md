## 二、新增功能清单

### 任务1：AI回复草稿生成（核心功能）

**1.1 收件箱增强**
- 覆盖原有 `viewInbox`，保留统计面板，每条客户回复新增「🤖 AI生成回复」按钮
- 点击后显示 loading → 调用 `callAI(purpose:'reply', timeout:90s)` → 渲染草稿
- 自动意图分类（6类）：感兴趣 / 需报价 / 已购买 / 退订 / 需样品 / 其他
- 草稿状态机：`draft（待审核）→ edited（已编辑）→ sent（已手动发送）`
- 草稿操作：展开/收起、textarea 编辑、保存编辑、复制到剪贴板（双语合并）、标记已发送、重新生成

**1.2 中英双语**
- 自动检测客户邮件语言（CJK vs Latin 字符比例）
- 主回复使用客户语言，自动附带另一语言翻译
- 输出格式：`===REPLY_START/END===` + `===TRANSLATION_START/END===` 分隔符，前端正则解析

**1.3 回复草稿管理页**
- 新导航项「💬 回复草稿」（key: `replyDrafts`）
- 统计卡片 + 状态筛选（待审核/已编辑/已发送）+ 意图筛选 + 品类筛选
- 标记已发送后：inbox 状态→已回复、客户 `lastInteraction` 更新、timeline 追加事件、`persist()`

**1.4 数据结构**
```js
S.replyDrafts = [{
  id, inboxId, customerId, customerName,
  intent: 'interested|quote|purchased|unsubscribe|sample|other',
  subject, body, translation,
  status: 'draft|edited|sent',
  createdAt, sentAt, modelUsed
}]
```

### 任务2：开发复盘看板增强

**2.1 核心指标卡片（6项）**

**2.2 多维度分析**
- **按品类**：户外刀/厨房刀/剪刀/厨房用品各自发送量、打开数、回复数、回复率，横向CSS柱状图

- **跟进效果**：第3天 vs 第7天跟进回复率对比

**2.3 CSV导出**
- 纯前端 Blob + BOM头（`\uFEFF`），Excel 可直接打开中文
- 文件名：`开发复盘_YYYYMMDD.csv`

### 任务3：A/B测试功能

**3.1 全流程**
- 列表页 → 创建模态框 → 随机分配 → 详情对比 → 显著性结论 → 优胜应用
- 创建时支持「基于历史优胜版本」下拉
- AI生成B版本变体：基于A版，换主题风格/卖点侧重/CTA措辞

**3.2 随机分配**
- 洗牌后 `Math.random() < 0.5` 50/50 分配，奇数尾包给A组
- 为每位客户生成 `S.drafts`（status='待检查'，带 `abTestId`/`abVersion`）
- **绝不自动发送**，用户手动审核后去企业邮箱发送

**3.3 统计显著性（Z检验）**
- 对打开率做双比例Z检验，p<0.05（双尾 |z|≥1.96）
- 公式：`z = (pA−pB) / √(p·(1−p)·(1/nA+1/nB))`
- 分母 n = 实际发送数（非分配数），数据透明
- 每组 <20 封直接返回「数据不足」，不妄下结论
- 已验证：20v20(60%vs30%)→z=1.91判无显著差异；30v30(20%vs50%)→z=−2.44判B显著优

**3.4 追踪关联**
- sendRecords 带 `abTestId` 时精确匹配，否则降级为 customerId + 时间窗匹配

### 任务4：沉睡客户唤醒

**4.1 自动识别**
- 条件A：有发送记录但超过14天无回复（含曾回复后再沉默）
- 条件B：超过30天无任何互动
- 排除：已成交、不再联系、blacklisted、unsubscribed
- 计算沉睡天数，存入 `S.dormantCustomers`

**4.2 三策略AI唤醒话术**
| 沉睡天数 | 策略 | 要点 |
|----------|------|------|
| 14-30天 | 轻触达 | 问候 + 分享行业资讯/新产品，不推销 |
| 30-60天 | 新价值 | 提供新产品/新认证/促销信息，引导回复 |
| 60天+ | 最后通牒 | 礼貌询问是否仍有需求，无回复则进入冷却 |

- 英文正文 + 中文翻译，调用 `callAI(purpose:'wakeup')`
- 草稿可编辑、复制、标记已手动发送

**4.3 冷却池**
- Tab切换「待唤醒 / 冷却中」
- 冷却90天，到期自动回到待唤醒列表

## 三、技术架构说明

### 3.1 模块注入模式
```
app.js (原始 renderView)
  → phase3-reply-timeline.js 包装 (拦截 replyDrafts)
    → phase3-analytics-dormant.js 包装 (拦截 p3Dashboard, dormantCustomers)
      → phase3-abtest.js 包装 (拦截 abTests, abTestDetail)
        → 原始 renderView
```
每个模块保存 `window.renderView` 为 `_origRV`，检查自身视图后委托给上一层，形成无冲突的责任链。

### 3.2 数据持久化
- `abTests`：app.js 原有 persist/loadState 已覆盖
- `replyDrafts` / `dormantCustomers` / `wakeupDrafts`：本阶段新增至 loadState/persist
- 所有新CSS class 以 `p3-` 前缀，避免污染

### 3.3 AI调用
- 全部复用现有 `callAI()` → `/api/ai/generate`（服务端模型路由，gpt-5.6-terra优先，故障转移glm/ollama）
- 无新增后端API端点，server.js 零修改
