## 二、新增功能清单

### 2.1 GPT 中转站 API 集成（模型路由层）

- **新增 `callOpenAIProxy()`**：通用 OpenAI 兼容调用，支持 `https://wawapi.top/v1`
- **新增 `getModelProvider(model)`**：返回 `openai_proxy | glm | ollama`，按模型名自动分发
- **`MODEL_CHAINS` 重排**：
  - text: `gpt-4o → gpt-4o-mini → glm-4-flash → qwen3.5:9b → qwen2.5:7b`
  - reasoning: `gpt-4o → glm-4-flash → qwen3.5:9b → deepseek-r1:7b`
  - vision: `gpt-4o → glm-4.6v-flash → qwen3.5:9b → qwen2.5vl:7b`
- **新增 `OPENAI_PROXY_MODELS`**：gpt-4o / gpt-4o-mini / gpt-4-turbo / claude-3-5-sonnet / gemini-2.0-flash
- **故障转移修复**：404 "模型不存在" 归类为 `model_not_available`，允许自动切换到下一模型（关键修复，否则中转站模型不可用时整条链卡死）
- **`getModelHealth()`** 新增 `providerOrder`、`openaiProxyModels`、providers 配置状态（不返回 apiKey）

### 2.2 品类知识 API（后端）

- **`GET /api/category/list`**：返回四品类元数据 + 搜索关键词模板
- **`GET /api/category/knowledge?category=xxx`**：返回材质/卖点/认证/MOQ/包装/HS编码/摘要
- 数据全部来自 `公司知识库/02_产品知识库/00_四大品类产品参数汇总_确认版.md`（v5.7）
- 缺数据项标注"⚠️待工厂确认"，未编造
- 所有路由走 `requireAuth`，未认证返回 401

### 2.3 四品类客户搜索（前端）

- **搜客页面品类选择器**：自动搜客页 + 精准开发页顶部各增加四品类按钮
- 点击品类后自动填充对应英文搜索关键词到搜索框
- 搜索结果卡片显示品类徽章
- 导入客户台账时自动写入 `productCategory` 字段

### 2.4 客户台账品类字段

- 客户对象新增 `productCategory` 字段
- 客户新增/编辑表单增加品类下拉选择
- 客户列表增加品类筛选下拉（含"未分类"选项）
- 客户表格增加品类列
- 客户详情抽屉显示品类标签
- 线索转客户自动带入品类

### 2.5 知识库驱动个性化开发信

- 生成开发信时自动读取客户 `productCategory`
- 调用 `/api/category/knowledge` 获取品类知识
- 注入 `[Product Category Knowledge]` 块到 AI prompt，强制要求至少引用 2 个具体卖点
- 开发信包含：个性化开头 + 知识库卖点 + CTA + KaiLionCrafts/Leo Li 签名
- 保持现有 12 项质检和 Fact 验证体系不变
- 客户无品类时提示先选择品类

### 2.6 开发信编辑器"插入品类知识"按钮

- 编辑器正文下方增加"📚 插入品类知识"按钮
- 点击弹出浮层，显示当前客户品类的关键卖点列表
- 点击卖点自动插入到编辑器光标位置
- 浮层顶部可切换品类查看其他品类知识
- 手机端浮层固定底部，响应式适配

### 2.7 设置页 GPT 中转站状态 + 手动模型切换

- 新增 GPT 中转站状态卡（已配置/未配置 + 当前模型）
- 手动模型下拉：gpt-4o / gpt-4o-mini / gpt-4-turbo / claude-3-5-sonnet / gemini-2.0-flash / glm-4-flash / 本地模型
- 选择后存入 `S.settings.aiManualModel`，开发信生成时作为 `manualModel` 传入

## 六、⚠️ 重要注意事项

### 6.1 中转站 wawapi.top 当前模型不可用
- 端点和 API Key **有效**（返回结构化 404 而非 401 认证错误）
- 但该中转账号当前 **5 个模型全部返回**：`Model "xxx" is not supported by any configured account in this group`
- **这不是代码问题**，需登录 wawapi.top 后台检查账号分组的模型路由/余额/模型绑定
- **在修复前**，所有 AI 请求会自动故障转移到 GLM（已验证可用），不影响工作台使用
- 代码已确保 404 触发故障转移，不会卡死在 gpt-4o

### 6.2 绝对不自动发送邮件
- 本次新增功能**没有任何**自动发送邮件的代码
- 开发信只生成内容，"发送"操作仍需用户手动去企业邮箱完成
- 现有 SMTP 配置 UI 为原有代码，未被修改

### 6.3 已有客户数据
- 现有客户默认 `productCategory` 为空（显示"未分类"）
- 需在客户编辑表单中手动补选品类后，才会触发知识库驱动的开发信生成

### 6.4 免费工具
- 全部使用免费方案：GPT 中转站（用户已有）、GLM（免费）、Ollama 本地（免费）、Tavily 搜索（已有免费额度）
- 未引入任何付费服务
