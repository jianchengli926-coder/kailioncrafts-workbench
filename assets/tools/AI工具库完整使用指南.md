## 二、锴利自研AI工具库（7个HTML工具）

> 入口：左侧菜单「🛠️ 锴利自研AI工具库」
> 特点：纯前端HTML，本地运行，数据不上传，支持批量处理

### 🏷️ 1. SKU命名工具

**功能**: 超级图片命名工具v4，产品SKU和SEO文件名一键生成

**作用**:
- 产品库命名：选择品类自动生成标准SKU和SEO文件名
- 自定义生成：手动输入产品信息生成命名
- 批量重命名：批量处理图片文件命名
- 材质代码表：查看钢材、手柄等材质代码
- SEO关键词库：内置SEO优化关键词

**使用方法**:
1. 选择命名模式（产品库/自定义/批量）
2. 填写产品信息（品类、材质、手柄等）
3. 点击生成，获取SKU和SEO文件名
4. 批量模式可导入文件夹自动重命名

**注意事项**:
- SKU命名规则：KL-[品类缩写]-[材质缩写]-[序号]
- SEO文件名全小写，用短横线连接，包含产品核心关键词
- 批量重命名前务必备份原文件

### ✏️ 2. 产品线稿工具

**功能**: 批量智能线稿转化工具，产品图片转线稿图

**作用**:
- 批量导入产品图片，自动转化为线稿
- 在当前图上添加专有标注（尺寸、材质等）
- 清除当前图所有标注
- 导出当前显示的高清图(PNG)
- 自动批量导出所有产品线稿

**使用方法**:
1. 点击批量导入产品图片
2. 系统自动转化为线稿
3. 可添加标注（尺寸线、材质说明）
4. 单张导出或批量导出所有线稿

**注意事项**:
- 线稿适合用于产品说明书、包装设计、技术文档
- 标注功能可添加尺寸线和文字说明
- 导出为PNG格式，支持高清分辨率

### 🎨 3. 全品类视觉矫正

**功能**: 4K独立站主图矩阵系统，产品主图统一处理

**作用**:
- 全员强制左右反转：统一产品朝向
- 一键直接导出所有4K纯净PNG
- 支持全品类产品（刀剪、户外、厨房用品）
- 纯净画质无缝处理

**使用方法**:
1. 导入产品主图
2. 系统自动进行视觉矫正
3. 如需统一朝向，点击左右反转
4. 一键导出所有4K纯净PNG

**注意事项**:
- 独立站主图建议统一朝向（刀头朝右/朝左）
- 导出为4K分辨率PNG，文件较大
- 处理前保留原图备份

### 💡 4. 刀剪产品提示词

**功能**: 刀剪外贸独立站AI生图Prompt场景知识库

**作用**:

4. 复制生成的Prompt到Midjourney/DALL-E等工具

**注意事项**:

- 可根据需要修改Prompt中的材质、颜色等参数

## 三、独立站上品SEO工作台

> 入口：左侧菜单「📦 独立站上品SEO工作台」
> 作用：商品上架SEO全流程工作流，Rank Math评分84+

### 5步工作流

| 步骤 | 功能 | 说明 |
|------|------|------|
| 1.品类判定 | 填写产品信息 | SKU、品类、材质、手柄、工艺、MOQ、尺寸 |
| 2.联网搜索 | 上传图片+生成搜索Prompt | 以图搜图，阿里巴巴/亚马逊竞品分析 |
| 3.参数收集 | 搜索结果整理 | 价格、尺寸、材质、竞品卖点、客户评价 |
| 4.SEO生成 | 生成22模块SEO内容 | 完整商品上架内容，Rank Math 84+分 |
| 5.评分检查 | 11项自检清单 | URL/标题/正文/关键词/图片SEO检查 |

### 使用方法
1. 填写产品SKU和参数
2. 上传产品图片
3. 点「生成联网搜索Prompt」→ 复制到豆包专家模式 → 上传图片 → 让AI联网搜竞品
4. 点「生成SEO内容生成Prompt」→ 结合搜索结果 → 让AI生成22模块完整内容
5. 按11项自检清单检查评分
6. 复制内容到WooCommerce后台上架

### 注意事项
- 联网搜索需要在豆包专家模式中进行（工作台本身不联网）
- 生成的内容直接复制粘贴到WooCommerce后台
- 每个产品的SEO文档保存为txt格式
- Rank Math 84+分核心规则：URL≤40字符、标题含情感词+强力词、正文680-720词、关键词密度1.8-2.1%

## 七、通用注意事项

1. **数据安全**: 所有HTML工具本地运行，图片不上传服务器
2. **备份**: 批量处理文件前务必备份原文件
3. **知识库更新**: 新知识库通过「🗂️ 知识库管理」页面添加
4. **多人访问**: 绑定0.0.0.0，局域网同事通过IP访问
5. **模型选择**: 简单查资料用本地模型，复杂任务用在线大模型
6. **产品SEO**: 上品必须按工作流5步走，确保Rank Math 84+分
7. **客户开发**: 开发信/背调需要联网，用在线模型
8. **团队协作**: 4人各有工作空间，生成内容可推送到总知识库
