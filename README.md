# 方舟外贸获客工作台 V3.0

一款基于外贸获客五步闭环逻辑的AI驱动外贸客户开发工作台，单文件HTML，双击即用，数据全在本地。

## 核心理念

- **AI干脏活累活**：搜索 → 核证据 → 写草稿
- **人做关键决策**：检查 → 发送 → 跟进
- **数据全在本地**：localStorage存储，不离开电脑
- **重质量不重数量**：不是找名单，而是判断谁值得联系

## 五步闭环

```
找客户 → 核证据 → 写草稿 → 人工发送 → 跟进转化
```

## V3.0 核心升级：真实API接入

### 支持三种模型类型

| API类型 | Base URL | 模型示例 |
|---|---|---|
| OpenAI兼容中转站 | 自定义（如 https://wawapi.top/v1） | gpt-3.5-turbo, gpt-4o |
| 智谱AI GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash, glm-4-plus |
| 本地Ollama | http://localhost:11434/v1 | qwen2.5, deepseek-r1 |

### 真实API调用的功能
- 客户背调报告生成
- 客户匹配度四维评分
- 个性化开发信起草
- 收件箱AI回复建议
- 询盘AI回复建议
- 报价单AI生成
- 全局AI助手（右下角悬浮球，多轮对话）

### API配置中心
- 多API配置管理（启用/禁用/设默认/编辑/删除）
- 连接测试（显示延迟+token消耗）
- 功能开关勾选式
- API Key密码掩码存储
- 无API时自动回退模拟模式

## 使用方式

1. 双击 `index.html` 在浏览器中打开
2. 首次使用进入「设置 → 重置演示数据」加载完整演示数据
3. 进入「设置 → API配置」启用你的AI模型并测试连接
4. 设为默认模型后，所有AI功能自动调用真实API

## 技术栈
- 纯HTML + CSS + JavaScript（单文件，零外部依赖）
- localStorage本地数据存储
- ECharts（CDN）数据可视化
- OpenAI兼容 /chat/completions API协议

## 数据安全
- 所有客户数据、API Key均存储在浏览器本地localStorage
- 不上传任何数据到外部服务器
- API调用直接从浏览器发往你配置的API端点
- 支持全量数据导出备份
