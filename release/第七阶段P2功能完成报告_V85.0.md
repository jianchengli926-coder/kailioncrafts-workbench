## 二、15 项功能详细说明

### 功能 21：AI 学习反馈环（人工修改回流知识库）

**导航**：🔮 AI学习中心 → 3 个 Tab（学习记录 / 学到的模式 / 学习统计）

**核心能力**：
- **修改记录**：当用户修改 AI 生成的开发信/回复草稿时，通过 `window.p7RecordEdit(customerId, draftType, originalSubject, originalBody, modifiedSubject, modifiedBody)` 自动记录修改前后对比，计算 diff 摘要
- **模式分析**：点击"分析修改模式"按钮，AI 分析最近的学习记录，识别高频修改模式（哪些部分经常被改、哪些表达被替换、哪些卖点被删除），写入"学到的模式"库
- **最佳实践注入**：`window.p7GetActivePatternsPrompt()` 返回已启用模式的 prompt 片段，供其他模块在 AI 生成时自动注入最佳实践指导
- **学习统计**：累计学习次数、最常修改的部分（div 柱状图）、学习效果对比

**状态字段**：`S.p7LearningRecords`、`S.p7LearnedPatterns`、`S.p7LearningStats`

### 功能 22：自然语言跟进规则

**导航**：🔮 AI学习中心 → "自然语言规则" Tab

**核心能力**：
- 用户用自然语言定义规则，如"客户提到预算超过$5000时立即通知我"
- AI 解析为结构化条件 `{field, operator, value}` + 动作 `action`
- 支持条件字段：`budget`、`deliveryTime`、`competitor`、`certification`、`quantity`、`replyStatus`
- 支持操作符：`gt`、`lt`、`eq`、`contains`、`mentions`
- 动作类型：`notify`（提醒）、`generate_draft`（生成回复草稿建议）、`tag`（标记客户）
- `window.p7CheckRules(customerId, context)` 触发检测，仅生成 toast 提醒/草稿建议/客户标签，**绝不自动执行外部操作**
- 规则列表：启用/禁用开关、触发条件展示、执行动作、触发次数、触发历史

**状态字段**：`S.p7NlRules`、`S.p7RuleTriggers`

### 功能 23：Predictive Sending（按个人最佳发送时间）

**导航**：⏰ 最佳发送时间

**核心能力**：
- 分析每个客户的历史打开时间（`S.sendRecords` 中 `openStatus='opened'` 的记录）
- 统计：客户所在时区（内置 16 国外贸时区映射表）、历史打开时间分布（0-23 小时柱状图）、最佳发送时段、最佳发送星期
- 全局统计：哪个时段发送的邮件打开率最高
- 客户列表：每个客户显示预测最佳发送时间、置信度、历史打开次数
- 数据不足（打开记录 <3 条）的客户显示"数据不足，建议默认上午 9-11 点发送"
- 提供"重新分析全部客户"按钮

**状态字段**：`S.p7BestSendTimes`

**注意**：时区映射为简化版（UTC 整数偏移），未处理夏令时，作为参考使用。

### 功能 24：OpenStreetMap Overpass 免费本地商家搜客源

**导航**：🗺️ OSM搜客

**核心能力**：
- 集成 OpenStreetMap Overpass API（完全免费），按地理位置搜索本地商家
- 搜索条件：品类（kitchen 厨房用品 / knives 刀具 / outdoor 户外用品 / general 综合）、城市、国家、搜索半径（默认 5000m）
- 返回商家名称、地址、坐标、网站、电话、邮箱、品类标签
- 每个结果可"导入客户台账"：创建新客户记录（`source='OSM'`，`tags=['osm_found']`），导入前做 website+name 去重
- 搜索历史保存，可按名称/距离排序
- 后端 `/api/osm/search` 实现：24 小时结果缓存 + 3 秒速率限制（Overpass 免费 API 要求）

**后端 API**：`POST /api/osm/search`  
**状态字段**：`S.p7OsmSearches`、`S.p7OsmCache`

**注意**：Overpass 免费公共实例可能返回 504（过载），UI 提示"免费 API，搜索间隔约 3 秒，请耐心等待"。

### 功能 28：MCP Server（基础版）⚠️ 简化版

**导航**：🔧 MCP Server

**核心能力**：
- 实现 HTTP 基础版 MCP（Model Context Protocol）server，将工作台能力暴露给 AI 助手
- 暴露 5 个工具：`search_customers`、`get_customer_detail`、`generate_outreach_draft`、`list_send_tasks`、`query_knowledge`
- 配置面板：启用/禁用开关、端口说明（工作台端口 8080）、访问密钥（自动生成随机字符串，可复制/重生成）

- 工具列表展示：调用 `GET /api/mcp/tools` 异步加载，显示名称/描述/参数 schema

- 外部接入说明：mcp.json 配置示例，说明本实现为 HTTP 基础版（非标准 stdio MCP）

**后端 API**：`GET /api/mcp/tools`、`POST /api/mcp/call`  
**状态字段**：`S.p7McpConfig`

**简化说明**：这是开发者功能，实现基础 HTTP 版即可，不需要完整 MCP SDK 或 stdio 传输。`generate_outreach_draft` 工具仅返回模板，不调用 AI 生成。

### 功能 30：知识库 → GEO 内容映射

**导航**：🌐 GEO内容

**核心能力**：
- GEO 体系：**Generate**（生成）→ **Enrich**（丰富）→ **Optimize**（优化）
- **Generate**：选择产品品类（户外刀具、厨房刀具、剪刀、厨房工具）和内容类型（产品描述 product / 博客文章 blog / 落地页文案 landing），AI 调用 `callAI` 生成 SEO 内容草稿，prompt 中注入 `S.companyFacts` 公司事实。生成内容包含：标题、Meta Description、正文（含 H2/H3 结构）、目标关键词、长尾词建议
- **Enrich**：对已生成内容，AI 增加关键词密度、补充长尾词、增加内部链接建议，显示丰富前后对比
- **Optimize**：本地确定性 SEO 评分（0-100），检查清单：Title 长度（50-60 字符）、Meta Description 长度（150-160）、H1 唯一、H2-H3 层级、关键词密度、图片 alt 建议、内链建议，给出具体改进建议
- 内容导出：支持 Markdown 和 HTML 两种格式（Blob 下载）
- 历史内容列表：查看/编辑/导出
- 与 kailioncrafts.com SEO 策略联动：内容可直接用于独立站产品页/博客/落地页

**状态字段**：`S.p7GeoContents`

### 功能 31：AI 谈单监测（识别谈单卡点）

**导航**：🎯 谈单监测

**核心能力**：
- AI 分析客户沟通历史（`S.inbox` 中该客户的邮件 + `S.drafts` + `S.sendRecords` + 时间线），识别谈单卡点
- 5 类卡点：
  - **price** 价格卡点：客户反复议价
  - **delivery** 交期卡点：客户担心交期
  - **quality** 质量卡点：客户要求认证/检测
  - **decision** 决策卡点：客户需要上级批准
  - **competitor** 竞品卡点：客户在对比竞品
- 每个卡点给出：描述、突破建议、推荐英文话术（talk track）
- 谈单健康度评分 0-100，低于 40 显示红色预警
- 客户列表按健康度升序排列（最危险的在前），点击可展开详细卡点分析抽屉

**状态字段**：`S.p7NegotiationAnalysis`（key=customerId）

### 功能 32：自然语言查数据（NL2SQL）⚠️ 简化版

**导航**：🔮 AI学习中心 → "智能查询" Tab

**核心能力**：
- 预定义 6 个常见问题模板：

- 查询结果：答案文字 + 简单数据表格
- 查询历史保存，可点击重新查询/删除

**状态字段**：`S.p7NlQueryHistory`

**简化说明**：不需要完整的 NL2SQL 引擎，用预定义模板匹配 + AI 补充即可。

### 功能 35：多模型编排 ⚠️ 简化版

## 六、已知限制与注意事项

1. **OSM 搜索速率**：Overpass 免费公共实例有速率限制（后端已加 3 秒间隔 + 24 小时缓存），高峰期可能返回 504，提示用户稍后重试
2. **时区映射**：Predictive Sending 的时区表为简化版（UTC 整数偏移），未处理夏令时（DST），最佳发送时间作为参考
3. **AI 学习数据积累**：功能 21 的学习反馈环需要其他模块（如草稿页）在用户保存修改时主动调用 `window.p7RecordEdit()` 才能积累数据，当前版本已挂在 window 上供外部调用
4. **MCP 兼容性**：功能 28 为 HTTP 基础版 MCP，非标准 stdio MCP，适用于支持 HTTP MCP 的客户端（如部分 Cursor 配置）
5. **PDF 打印**：功能 26 的 PDF 生成使用浏览器打印功能，需要用户允许弹窗，打印对话框中选择"另存为 PDF"
6. **谈单分析速度**：功能 31 批量分析全部客户时为串行 AI 调用，客户数量多会较慢，会逐条 toast 提示
